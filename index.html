About WavToFM

WavToFM is a sound generation diversification and archiving utility built around the Yamaha DX7 FM synthesis engine.

FM synthesis is uniquely suited for this purpose: it consumes very little CPU, needs minimal storage, and sounds consistent across the entire pitch range without temporal distortions. A single 128-byte patch can reproduce a sound at any MIDI note, instantly.

This makes FM ideal for drafting musical ideas on low-end hardware — devices where sample-based playback would be too expensive. Projects like LittleGPTracker and trkr already use FM for this reason.

WavToFM takes any audio recording and finds the closest DX7 patch using genetic algorithms, spectral analysis, and neural network prediction. The result is a portable, lightweight voice you can use anywhere — from a tracker on a Raspberry Pi to a browser on a phone.

Help

Import a .WAV — Upload an audio recording. The server analyzes it and returns the closest DX7 patches. Click patches to preview, drag stars to the night sky to organize.

Import a .SYX — Load a DX7 sysex bank (32 voices). All patches are shown in a list. Click to play, drag to the night sky to collect favorites.

Night Sky — A free canvas where patches live as floating cards. Drag stars from any list to place them. Click to expand/collapse. Create containers to group patches.

Piano Dock — Bottom panel with Keyboard (click to play), Piano Roll (draw note sequences), and Log (activity history).

Edit — Morph between two patches, tweak individual parameters, or generate random mutations.

Export .SYX — Save your collected patches as a standard DX7 sysex file.
